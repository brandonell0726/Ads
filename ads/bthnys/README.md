# BTHNYS — client (activewear)

Brandon's client. They gave permission to use their set in ads (2026-10-22). Brand name spelled **bthnys** (shown as BTHNYS on end cards).

The set: a butter-cream fitted tank with thin double straps and a cream polka-dot halter bra layer underneath, plus matching cream high-rise bike shorts with a wide fold-over polka-dot waistband. A small silver-grey script logo is embroidered on the chest and the upper thigh. Reference photos were from their Paris shoot. The animations show only fictional people, or none, never the model from those photos.

## 2. 30 s TV commercial, 16:9: "One set. Every world." (done 2026-10-22)

The script in `commercial-script.md` was approved by Brandon ("go"). It ends with all four walking down the desert road, then a cream end card with the 3D set and BTHNYS.
