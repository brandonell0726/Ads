All pages were fetched or searched on 2026-11-04 unless another date is given. Dates next to numbers are the source's own date. Related notes in this folder already cover Google Search enforcement in depth (`content_sites_ads_affiliate.md` Q3), YouTube Partner Program rules (`video_social_creator_income.md` Q1) and software maintenance costs (`software_tools_microsaas.md` Q6). ## 1. What can run on a schedule without a person (Claude Code scheduled tasks, Claude API, GitHub Actions, n8n/Make/Zapier, publishing APIs), and which steps still need a human

### Takeaway
Claude Code cloud scheduled tasks (formerly "routines") can run a full Claude session every hour or less often, with repos and connectors, and they keep running with the laptop closed. Model costs are small: cents per article on the API, or included in a $20–$200 a month Claude plan. Identity and tax checks, payouts, account creation, publishing approvals on some APIs and every "send/publish to the public" decision still need Brandon. The feature is in research preview, and a run that "Succeeded" may still have done nothing useful, so someone has to read the run logs.

### Cited Findings
**Claude Code cloud scheduled tasks (official docs, fetched 2026-11-04)**
- Scheduled tasks are "in research preview. Behavior, limits, and the API surface may change." A task is "a saved Claude Code configuration: a prompt, one or more repositories, and a set of connectors" that runs "on Anthropic-managed cloud infrastructure… so they keep working when your laptop is closed." — [Claude Code docs: scheduled tasks](https://code.claude.com/docs/en/routines)
- Triggers: a schedule (hourly, nightly, weekly or a one-off time), an API trigger (an HTTP POST with a bearer token) or GitHub events. Available on Pro, Max, Ultra, Team and Enterprise. Created at claude.ai/code/routines or with `/schedule` in the CLI. — [Claude Code docs](https://code.claude.com/docs/en/routines)
- Minimum interval: "Expressions that run more often than once per hour are rejected." Runs scheduled exactly on the hour "can start several minutes late." — [Claude Code docs](https://code.claude.com/docs/en/routines)
- Limits: tasks "draw down subscription usage the same way interactive sessions do." Hourly caps are 100 scheduled runs an hour per account, and 30 an hour per task shared by Run now, API fires and re-runs. "None of these hourly limits has overage." Once the subscription limit is reached, runs are rejected unless usage credits (metered overage) are turned on. — [Claude Code docs](https://code.claude.com/docs/en/routines)
- **Conflict on daily caps:** third-party launch coverage (April 2026) lists daily run caps of "Pro 5 · Max 15 · Team/Enterprise 25", and an older GitHub issue quotes "Your plan gets 3 daily cloud scheduled sessions." The current official page (fetched 2026-11-04) lists no daily cap, only the hourly limits and subscription usage. The daily caps may be stale or undocumented. — [DEV Community](https://dev.to/raxxostudios/claude-code-routines-run-your-automations-in-the-cloud-4783); [implicator.ai](https://www.implicator.ai/anthropic-ships-claude-code-routines-cloud-automations-that-run-without-your-mac/); [GitHub issue #40124](https://github.com/anthropics/claude-code/issues/40124); vs [official docs](https://code.claude.com/docs/en/routines)
- Runs start in auto mode, where a classifier allows or blocks actions. A run "still stops and waits for an answer" for actions matching an ask rule, or after repeated blocks. "The fired prompt is therefore not live user input and can't act as approval or consent for actions during the run." — [Claude Code docs](https://code.claude.com/docs/en/routines)
- Run status "Succeeded" means only that the session ended without a reported failure: "Blocked network requests, missing connector tools, and work Claude couldn't complete appear in the transcript rather than on the row." — [Claude Code docs](https://code.claude.com/docs/en/routines)
- Fragility: if the GitHub connection lapses, the task skips runs for up to 72 hours and then turns itself off. The default environment's "Trusted" network allows only an allowlist of package registries and dev domains, and other hosts fail with 403 `host_not_allowed` until the environment is changed to Custom or Full. Connectors go through Anthropic's servers and are not blocked. — [Claude Code docs](https://code.claude.com/docs/en/routines)
- Anything a task does through connectors "appears as you": commits carry Brandon's GitHub user and messages use his linked accounts. — [Claude Code docs](https://code.claude.com/docs/en/routines)

**Claude plans and API pricing (fetched 2026-11-04)**
- Consumer plans: Free $0 (no Claude Code, no scheduled tasks); Pro $20/mo ($17/mo billed $200 a year); Max $100/mo; Ultra $200/mo. Pro and higher include "Hand off and schedule tasks." — [claude.com/pricing](https://claude.com/pricing)
- API per million tokens (input/output): Claude Opus 5.5 $4/$20; Claude Sonnet 5.5 $2/$10; Claude Sonnet 5 $2/$10 (the introductory price became standard; the planned Sept 1, 2026 rise to $3/$15 was cancelled); Claude Haiku 5.5 $0.10/$0.50 for prompts up to 100K tokens ($0.50/$2.50 above that); Haiku 4.5 $1/$5. — [Claude API pricing](https://platform.claude.com/docs/en/about-claude/pricing)
- Batch API: "50 percent discount on both input and output tokens" for asynchronous jobs. Cache hits on Opus/Sonnet 5.5 cost 0.05× base input. Web search costs "$10 USD per 1,000 searches" plus tokens. Claude 4.7 and later models use a tokenizer that "produces approximately 30% more tokens for the same text." — [Claude API pricing](https://platform.claude.com/docs/en/about-claude/pricing)

**GitHub Actions (fetched 2026-11-04)**
- GitHub Free personal accounts include "$12 USD" of compute a month (about 2,000 Linux 2-core minutes at $0.006/min) and 500 MB of artifact storage. Standard runners in public repositories are free and don't count against that. — [GitHub Docs: Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions)
- "The shortest interval you can run scheduled workflows is once every 5 minutes." The schedule "can be delayed during periods of high loads." "In a public repository, scheduled workflows are automatically disabled when no repository activity has occurred in 60 days." — [GitHub Docs: events that trigger workflows](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows)

**No-code automation pricing (fetched 2026-11-04 unless noted)**
- n8n cloud, billed annually: Starter €20/mo for 2.5K executions; Pro €50/mo for 10K; Business €667/mo for 40K. "A standard, self-hosted version of n8n is available on GitHub." The page doesn't say whether self-hosting is free. — [n8n pricing](https://n8n.io/pricing/)

**Publishing APIs (automation gatekeepers)**
- TikTok Content Posting API: "All content posted by unaudited clients will be restricted to private viewing mode." The client "must undergo an audit," and the creator must have authorized the app for the `video.publish` scope. — [TikTok for Developers](https://developers.tiktok.com/doc/content-posting-api-get-started)
- YouTube Data API `videos.insert`: the official page (fetched 2026-11-04) now says "Videos uploaded from unverified API projects are not restricted to private viewing mode." The upload method lists 100 calls a day. Secondary and developer sources still describe the older rule (projects created after July 28, 2020 are locked to private until audited). This looks like a recent change, but I couldn't confirm its date. — [YouTube Data API: videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert); older rule per [Ayrshare](https://www.ayrshare.com/solutions/google-api-error-403-unverified-app-how-to-fix-the-audit-pipeline/) and [GitHub issue](https://github.com/porjo/youtubeuploader/issues/86)

**Steps that need a human (identity, tax, payouts)**
- AdSense (USD): tax information threshold $0; identity verification threshold $0 ("You must verify your identity before your account can start showing ads and receiving payments"); address verification threshold $10 (a PIN is mailed to the payment address); payment threshold $100. — [AdSense Help: thresholds](https://support.google.com/adsense/answer/1709871?hl=en)
- There are 45 days to submit identity documents once asked. The PIN must be entered within 4 months, or the YouTube channel is demonetized. — [AdSense Help: verification](https://support.google.com/adsense/answer/1709858?hl=en); [YouTube Help: PIN](https://support.google.com/youtube/answer/14727844?hl=en)
- Amazon Associates policies (updated April 14, 2026) prohibit artificially generating "clicks or impressions… by way of a robot or software program." They also require agents to "Not conceal or obfuscate that any access, use, or interactions are from an Agent." Associates may not bid on Amazon keywords, use links offline or in ebooks, or email links unless the email is "solicited (i.e., opted into by the receiving customer)." — [Amazon Associates Program Policies](https://affiliate-program.amazon.com/help/operating/policies)
- Anthropic's Usage Policy (the page shows effective Nov 12, 2026) prohibits: "Utilize automation in account creation or to engage in spammy behavior"; "Manipulate the sources from which search engines or AI systems draw answers"; "Distribute content through networks of fake or ostensibly independent outlets, websites, or accounts"; "fake reviews, or bots that claim to be human"; and "actions or behaviors that circumvent the guardrails or terms of other platforms." Consumer-facing chatbots "must disclose to users that they are interacting with AI rather than a human." — [Anthropic Usage Policy](https://www.anthropic.com/legal/aup)

### Inferences
- **What can run unattended:** research and trend scans, drafting articles and scripts, generating images and video through Higgsfield, updating a site's repo, building and deploying, checking links and prices, pulling analytics and writing reports, refreshing affiliate prices (Amazon allows 24-hour caching only), and preparing social posts as drafts. Scheduled tasks and GitHub Actions together cover all of this.
- **What needs Brandon:** opening and verifying every money account (AdSense ID and PIN, Amazon tax interview and bank, Stripe/Lemon Squeezy KYC, TikTok/YouTube accounts); passing CAPTCHAs (automating account creation or CAPTCHAs breaks Anthropic's policy and most platforms' terms); approving each public post or email (his own rule, and the docs say a fired prompt "can't act as approval or consent"); answering customers and refunds; and checking run transcripts each week, because "Succeeded" doesn't mean the work got done.
- **Cost example (my calculation, Nov 2026 prices):** a 1,500-word article on Sonnet 5.5 with about 10K input tokens of context, about 2.6K output tokens (allowing for the ~30% tokenizer uplift) and 5 web searches with about 30K tokens of results costs about $0.02 + $0.03 + $0.05 + $0.06 ≈ **$0.15**. Thirty articles a month is about $5. Haiku 5.5 is about 1/20 of that, and the Batch API halves either. Inside a Claude plan, the scheduled run is already paid for until usage limits hit. Model cost is not the barrier; traffic, approval and platform risk are.
- **Realistic monthly tool bill for a solo automated project:** Claude Pro $20 (or the plan he already has) + GitHub $0 (a public repo, or within $12 of credit) + domain about $1–2 + hosting $0–20 ≈ $25–45 a month. n8n/Make/Zapier are optional, because Claude scheduled tasks and GitHub Actions cover scheduling. Zapier's free 100 tasks and 15-minute polling are too small for real pipelines anyway.
- **Keep-alive traps:** GitHub disables scheduled workflows in public repos after 60 days without activity, Claude tasks turn off after 72 hours without GitHub access, and scheduled tasks are a research preview. "Set and forget for a year" is not supported by either platform's docs.
- **Social auto-posting:** TikTok's API makes unaudited apps post privately. Whether the Higgsfield connector's TikTok publishing tools go through an audited client is unknown and should be tested with one post before any plan depends on it.

### Gaps
- The official docs don't state a per-plan daily cap for scheduled tasks (the third-party "5/15/25 per day" figure is unconfirmed), or how many runs a Pro plan's usage really supports.
- I didn't check Meta (Instagram/Facebook) Graph API publishing limits or Pinterest API access rules.
- n8n's self-hosted license and cost weren't stated on its pricing page, and Make's official prices didn't render (third-party figures only).
- I didn't fetch Amazon Associates' tax-interview and payment thresholds (Amazon pages not checked).
- When the YouTube private-lock policy changed is unconfirmed.

## 2. Platform rules on automation and AI content that can get accounts banned (Google, Amazon Associates, YouTube, TikTok, Pinterest, Etsy), and evidence of mass bans in 2025–2026

### Takeaway
No major platform bans AI-made content outright. All of them ban or demonetize mass-produced, low-value, undisclosed or bot-driven activity, and enforcement has been large and sometimes wrong. YouTube wiped channels with 35M subscribers in January 2026, Pinterest wrongly mass-suspended accounts in spring 2025, and Amazon shut about 95% of the stores in one FTC-sued "AI automation" scheme. A Claude-run "publish lots automatically" business is the exact pattern these rules target.

### Cited Findings
- **Google spam policies (fetched 2026-11-04):** "Scaled content abuse is when many pages are generated for the primary purpose of manipulating search rankings," and it applies "no matter how it's created." One example: "Using generative AI tools or other similar tools to generate many pages without adding value for users." The spam definition now includes "attempting to manipulate generative AI responses in Google Search." "Thin affiliation" covers affiliate pages that copy merchant descriptions without original content. Expired-domain abuse and site reputation abuse are also listed. — [Google Search Central: spam policies](https://developers.google.com/search/docs/essentials/spam-policies)
- Google enforcement details (the March 2026 NationalToday scaled-content manual action and the effects of AI Overviews) are in `content_sites_ads_affiliate.md` Q3–Q4.
- **YouTube:** renamed "repetitious content" to "inauthentic content" in July 2025, covering "repetitive or mass-produced" content (see `video_social_creator_income.md` Q1 for the primary source). In January 2026 YouTube removed 16 channels with a combined 35M subscribers and 4.7B lifetime views (11 terminated, 5 wiped), estimated at about $10M a year in earnings, citing spam policies. Creators report that faceless channels that never used generative AI were also caught. — [The Next Web](https://thenextweb.com/news/youtube-ai-slop-crackdown-faceless-creators-collateral-damage); [Tribune.com.pk, Apr 18, 2026](https://tribune.com.pk/story/2589980/youtube-cracks-down-deletes-47b-views-of-ai-spam-videos)
- **TikTok:** requires creators to label realistic AI-generated content, reads C2PA Content Credentials and says it has labeled "over 1.3 billion" videos. In November 2025 it began testing a Manage Topics control that lets viewers see less AI-generated content in For You, plus invisible watermarks. Both cut the reach of AI-made content. — [TikTok Newsroom, Nov 24, 2025](https://newsroom.tiktok.com/more-ways-to-spot-shape-and-understand-ai-generated-content?lang=en-GB); [Engadget](https://www.engadget.com/social-media/tiktok-will-let-users-tone-down-the-amount-of-ai-content-in-their-feed-050100596.html)
- **Pinterest:** from late April 2025, a wave of unexplained suspensions hit users worldwide. On May 14, 2025 Pinterest admitted "over-enforcement" from an "internal error," denied that AI moderation caused it, and reinstated accounts. Appeals were slow, and the AI explanation is still disputed. — [TechCrunch, May 14, 2025](https://techcrunch.com/2025/05/14/pinterest-finally-admits-mass-bans-were-a-mistake-caused-by-an-internal-error/); [Social Media Today](https://www.socialmediatoday.com/news/pinterest-mistaken-account-suspensions/748161/)
- **Etsy:** the Creativity Standards (July 2024) put AI-generated work under "Designed by a seller" (not "Made by"), and AI use must be disclosed in the listing. A June 2025 edit reportedly requires items "based on a seller's original design." These come from seller blogs, not Etsy's own page. A claim of "17,000 listings removed in early 2025" is unverified. — [Listadum](https://www.listadum.com/blog/etsy-creativity-standards); [RankHero, Jun 20, 2025](https://blog.rankhero.com/2025/06/20/etsy-policy-changes/)
- **Amazon / marketplaces vs "AI automation" stores:** in the Click Profit case, "Amazon blocked, suspended, or terminated about 95% of the stores," and "over one-fifth of stores on Amazon earned nothing after fees" (FTC, Mar 18, 2025). In Automators AI, Amazon and Walmart "routinely suspended, blocked, or terminated the stores that defendants operated" (FTC, Feb 27, 2024). — [FTC: Click Profit](https://www.ftc.gov/news-events/news/press-releases/2025/03/ftc-acts-stop-click-profit-online-business-opportunity-has-cost-consumers-least-14-million); [FTC: Automators AI](https://www.ftc.gov/news-events/news/press-releases/2024/02/ftc-action-leads-ban-owners-automators-ai-e-commerce-money-making-scheme)
- **Amazon Associates:** bans robot-generated clicks, concealed agent access, keyword bidding, offline/ebook links, Amazon trademarks in domains, storing product images, and showing prices without a date/time stamp (policies updated Apr 14, 2026). — [Amazon Associates Program Policies](https://affiliate-program.amazon.com/help/operating/policies)
- **AI review generators:** in September 2024 the FTC charged Rytr, whose "Testimonial & Review" feature let subscribers generate "hundreds, and in some cases tens of thousands" of potentially false reviews. The order bars it from marketing review-generation services. — [FTC: Operation AI Comply, Sep 25, 2024](https://www.ftc.gov/news-events/news/press-releases/2024/09/ftc-announces-crackdown-deceptive-ai-claims-schemes)

### Inferences
- The biggest risk to a passive project is that the platform switches it off, not that Claude can't build it. Every traffic source Brandon would use (Google, YouTube, TikTok, Pinterest, Amazon) has shown in 2024–2026 that it can remove accounts in bulk, sometimes by mistake, with slow appeals.
- Safer patterns: fewer, genuinely useful pages or videos with Brandon's own footage or expertise; AI use disclosed; no account networks; no auto-posting at volume; one human review before anything goes public. Riskier: many AI pages a day, multiple faceless channels, reposted trending clips, AI "customer" testimonials.
- Brandon's existing rule (tell businesses samples are AI-generated; never present AI people as real customers) already matches TikTok labeling, YouTube disclosure, the FTC fake-review rule and Etsy disclosure. It should be kept for any passive project.
- Spread the risk: don't let one passive project depend on a single platform's algorithm. Own an email list or website as a fallback.

### Gaps
- I didn't fetch Etsy's official Creativity Standards page or TikTok's Community Guidelines on "unoriginal content" eligibility for For You.
- There is no official count of accounts banned for AI or automation on any platform. The figures circulating are from low-quality summaries.
- I found no Spanish-language-specific enforcement data.

## 3. Legal and tax for Brandon in Florida (LLC, FTC disclosures, self-employment and estimated tax, 1099-K/1099-NEC, W-9, Florida sales and local business tax)

### Takeaway
Brandon doesn't need an LLC to earn ad or affiliate money. A single-member LLC is taxed exactly like a sole proprietorship. The real obligations: (1) report all net profit on Schedule C and pay 15.3% self-employment tax once net earnings reach $400; (2) pay quarterly estimated tax; (3) register "elier.visuals" as a fictitious name if he isn't using an LLC of that name; (4) hold a Polk County local business tax receipt (if he lives in Polk); (5) put clear FTC affiliate disclosures next to every affiliate link, in Spanish when the content is Spanish. Form 1099-K thresholds went back to $20,000 and 200 transactions, and 1099-NEC/MISC rose to $2,000 for 2026 payments, so he may get few forms. The income is taxable anyway.

### Cited Findings
**Business structure and registration**
- A single-member LLC "is treated as an entity disregarded as separate from its owner." The individual owner "is subject to the tax on net earnings from self employment in the same manner as a sole proprietorship" and reports on Schedule C (IRS page updated Jul 27, 2026). — [IRS: Single-member LLCs](https://www.irs.gov/businesses/small-businesses-self-employed/single-member-limited-liability-companies)
- Florida LLC: $125 to file Articles of Organization (including the $25 registered-agent designation), an annual report of $138.75 due by May 1 each year, and a reported $400 late fee (sources differ). A fictitious name (DBA) costs $50 and lasts 5 years. These are secondary guides; Sunbiz's fee page returned 403. — [ZenBusiness Florida fees](https://zenbusiness.com/florida-filing-fees); [How to Start an LLC](https://howtostartanllc.com:443/florida-llc/cost-to-form); [Sunbiz fees (blocked)](https://dos.fl.gov/sunbiz/forms/fees/)
- Polk County local business tax applies to "all individuals or firms doing business and which are located and/or operating in Polk County." Class "A" (non-state-regulated business) costs $39.38 a year, and Class "B" (state-regulated) $72.19. Renewal is due "no later than September 30th each year." City receipts are separate from county ones. — [Polk County Tax Collector: Local Business Taxes](https://www.polktaxes.com/services/local-business-taxes/)
- A Polk technical advisory says those "located in Polk County who engage in an internet business, and/or conduct internet sales transactions, in return for compensation would need to obtain a county local business tax receipt." The Tax Collector has a Davenport service center. — [Polk Tax Collector](https://www.polktaxes.com/?p=7428) (quote seen in a search snippet from a polktaxes.com technical advisory; I didn't confirm which page it came from)

**Federal income and self-employment tax**
- "The self-employment tax rate is 15.3%" (12.4% Social Security + 2.9% Medicare). The Social Security part applies to the first $184,500 of combined earnings in 2026. The employer-equivalent portion is deductible from income. An extra 0.9% Medicare tax applies above $200,000 for single filers (IRS page updated Oct 30, 2026). — [IRS: Self-employment tax](https://www.irs.gov/businesses/small-businesses-self-employed/self-employment-tax-social-security-and-medicare-taxes)
- "You have to file an income tax return if your net earnings from self-employment were $400 or more." Forms: Schedule C, Schedule SE and Form 1040-ES (estimated tax worksheet). — [IRS: Self-Employed Individuals Tax Center](https://www.irs.gov/businesses/small-businesses-self-employed/self-employed-individuals-tax-center)
- Estimated tax payment dates: income earned Jan 1–Mar 31 is due April 15; Apr 1–May 31 by June 15; Jun 1–Aug 31 by Sept 15; Sep 1–Dec 31 by Jan 15 of the next year. A payment due on a weekend or holiday is on time the next business day (IRS page updated Oct 2, 2026). — [IRS: Estimated tax FAQ](https://www.irs.gov/faqs/estimated-tax/individuals/individuals-2)

**Information returns (1099-K, 1099-NEC/MISC) and W-9**
- Form 1099-K: the One Big Beautiful Bill Act "retroactively reinstated" the old threshold. Payment apps and marketplaces file only if payments "exceeds $20,000 and the number of transactions exceeds 200" (IRS IR-2025-107, Oct 23, 2025). Secondary sources say the test applies per platform, there is no threshold for payment-card transactions, and some states set lower ones. — [IRS newsroom](https://irs.gov/newsroom/irs-issues-faqs-on-form-1099-k-threshold-under-the-one-big-beautiful-bill-dollar-limit-reverts-to-20000); [CPA Practice Advisor, Oct 23, 2025](https://www.cpapracticeadvisor.com/2025/10/23/irs-issues-new-faqs-on-20000-form-1099-k-threshold-under-obbba/171575/)
- Form 1099-NEC/1099-MISC: the threshold rises from $600 to $2,000 for payments made in 2026 (first reported in early 2027) and is indexed for inflation from 2027. Royalties stay at $10. The 24% backup withholding trigger (payee with no valid TIN/W-9) moves to $2,000 as well. Secondary sources (tax-software vendors and NATP), not IRS text. — [NATP blog](https://www.natptax.com/news-insights/blog/new-1099-rules-under-obbba-what-tax-pros-need-to-know-for-2026-and-beyond/); [TaxBandits](https://blog.taxbandits.com/form-1099-nec-instructions-for-2026-tax-year-a-complete-guide/)
- AdSense collects tax information at a $0 threshold, so it is required before the account goes live. — [AdSense Help: thresholds](https://support.google.com/adsense/answer/1709871?hl=en)

**FTC affiliate and endorsement disclosure (2023 Endorsement Guides)**
- The Guides "were revised in 2023 with… a new definition of 'clearly and conspicuously.'" Disclose "clearly and conspicuously on your site"; "The closer the disclosure is to your recommendation, the better." — [FTC: Endorsement Guides FAQ](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides)
- "Affiliate link" alone may not be understood. "Paid link" next to an affiliate link "should be an adequate disclosure." "Commissionable link" is "probably not a clear disclosure." A "single disclosure on your home page won't be sufficient," and neither is a hyperlinked "DISCLOSURE" button. Sample wording: "I get commissions for purchases made through links in this post." — [FTC FAQ](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides)
- Video: the disclosure should be "in the video itself," and the description alone is "not enough." A disclosure in comments is "easily avoidable." "#ad" or "Ad:" at the start of a post is probably effective; tagging a brand is not a disclosure. — [FTC FAQ](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides)
- **Spanish angle:** the connection "should be disclosed in whatever language or languages the endorsement is made." A Spanish post needs a Spanish disclosure. — [FTC FAQ](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides)
- The Guides "don't have the force of law," but violations can bring Section 5 actions, orders to pay consumers, and "substantial civil penalties" for parties that received a Notice of Penalty Offenses. Brands are "ultimately responsible for what others do on your behalf." — [FTC FAQ](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides)
- Amazon Associates separately requires "disclosing on your Site accurately and adequately and otherwise satisfying applicable legal requirements" (Apr 14, 2026). — [Amazon Associates Program Policies](https://affiliate-program.amazon.com/help/operating/policies)
- FTC Consumer Reviews and Testimonials Rule (16 CFR 465): announced Aug 14, 2024 and effective Oct 21, 2024. It bans fake reviews and testimonials, explicitly including AI-generated ones, and buying fake followers or views. The civil penalty is up to $51,744 per violation (2024), reported as $53,088 after the Jan 2025 inflation adjustment. — [Hunton](https://hunton.com/hunton-retail-law-resource/ftc-issues-final-rule-targeting-fake-consumer-reviews-and-testimonials-including-those-generated-by-artificial-intelligence-ai-and-online-bots); [Kelley Drye](https://www.kelleydrye.com/viewpoints/blogs/ad-law-access/ftc-finalizes-rule-on-fake-reviews)

**Florida sales tax on digital products**
- Majority view: Florida does not tax electronically delivered software or digital downloads, while software on physical media is taxable at 6%. Florida ruling TAA 02A-052 treats a download with no tangible media as not a sale of tangible personal property, and Rule 12A-1.032 is cited for the same point. Some secondary vendor pages say e-books and downloads are taxable, so sources conflict. — [Sales Tax Handbook: Florida](https://www.salestaxhandbook.com/florida/sales-tax-taxability/software-and-digital-products); [TAA 02A-052 summary](https://ezel.ai/tax-rulings/fl/taa-02a-052-software-license-renewals); conflicting: [Kintsugi](https://www.trykintsugi.com/quick-reads/which-digital-products-are-specifically-taxable-under-florida-sales-tax-rules)
- The Florida DOR will not accept "post office boxes and private mailboxes as physical location addresses" for sales-tax registration. — [Florida DOR FAQ](https://floridarevenue.com/faq/Pages/FAQDetails.aspx?FAQID=1290&IsDlg=1)

### Inferences
- **An LLC is optional.** It adds no tax benefit by default and costs $125 to form plus $138.75 a year from the second year. Its value is liability separation, which matters more for client video work (contracts, music and likeness claims) than for an ad-supported site. Brandon could stay a sole proprietor, register the fictitious name "elier.visuals" ($50 for 5 years; Florida requires this when trading under a name other than your legal name, under Fla. Stat. §865.09, not re-verified here), and form an LLC once revenue or client contracts justify it. An LLC filing also makes its principal address public on Sunbiz. Given the repo's note about not publishing a home address, he could use a registered agent or virtual office address.
- **Florida has no personal state income tax** (well established; not re-fetched in this pass). Brandon's tax is federal only: income tax plus 15.3% SE tax.
- **A rule of thumb for him:** set aside about 25–30% of net passive and side profit for federal tax. Because SE tax alone is 15.3% on about 92.35% of profit, even $3,000 a year of net affiliate or AdSense profit means about $424 of SE tax plus income tax. This is my calculation from the IRS rates; a tax pro should confirm his bracket.
- **Payers:** Google (AdSense) and Amazon will ask for W-9 data (SSN, or an EIN if he gets one; a free EIN keeps his SSN off payer forms). Under the 2026 rules he'll likely get no 1099-NEC/MISC below $2,000 from a payer, and no 1099-K below $20K and 200 transactions, but all of that income still goes on Schedule C.
- **County:** "Four Corners" spans Polk, Osceola, Lake and Orange counties. The business tax receipt depends on which county (and city, if inside Davenport city limits) his home is in. Polk is $39.38 a year for a non-regulated business.
- **Sales tax:** ad revenue and affiliate commissions aren't sales to consumers, so no Florida sales tax collection is needed for an AdSense or affiliate site. Selling digital downloads to Floridians is probably exempt (majority view), but should be confirmed with the DOR before launching a paid digital product. Selling through Etsy, Gumroad or a merchant of record moves collection to the platform in most cases (inference; not verified for Florida specifically).
- **Disclosure templates:** every affiliate block and video should carry "Paid link / Enlace pagado. I earn a commission if you buy (Gano una comisión si compras)," placed in the content itself and in the video's spoken or on-screen text, not only in the footer or description.

## 4. The scam landscape: FTC and court actions 2023–2026 against "AI-powered passive income" and e-commerce automation schemes, red flags, and how many people actually earn meaningful side income

### Takeaway
The phrase "AI-powered passive income" has been the core pitch of at least seven FTC cases since 2023, with tens of millions lost in each. Click Profit, sued in South Florida, charged at least $45,000 per buyer and saw about 95% of its Amazon stores shut down. Real side income is modest: Bankrate's 2025 survey puts the median side hustle at $200 a month, and the share of Americans with a side hustle fell to 27%.

### Cited Findings
**FTC cases (primary FTC press releases unless noted)**
- **Automators AI** (settlement Feb 27, 2024): promised "passive investment income" from AI-powered stores on Amazon and Walmart through a "proven system." "The vast majority of clients did not make the promised earnings or even recoup their sizable investment," and the platforms routinely suspended the stores. Judgment $21,765,902.65, partially suspended; a permanent ban on e-commerce business opportunities and coaching for most defendants; contract clauses blocking negative reviews unenforceable. Consumers invested about $22M (secondary). — [FTC, Feb 27, 2024](https://www.ftc.gov/news-events/news/press-releases/2024/02/ftc-action-leads-ban-owners-automators-ai-e-commerce-money-making-scheme)
- **FBA Machine / Passive Scaling** (filed June 2024): "guaranteed income" from stores run by "AI-powered" software, a "7-figure business," testimonials of clients who "generate over $100,000 per month in profit," called "risk-free" with refund guarantees. Buyers invested tens to hundreds of thousands of dollars; losses were more than $15.9M. A later settlement reportedly bans the operator (status: confirm on the FTC page). — [FTC: Operation AI Comply, Sep 25, 2024](https://www.ftc.gov/news-events/news/press-releases/2024/09/ftc-announces-crackdown-deceptive-ai-claims-schemes)
- **Ascend Ecom** (Sept 2024): "cutting edge" AI tools for "passive income" of thousands a month and "five-figure monthly income" by year two. Tens of thousands to start plus tens of thousands for inventory; at least $25M lost. Pressured buyers to change negative reviews and didn't honor its "guaranteed buyback." Placed under a receiver. — [FTC, Sep 25, 2024](https://www.ftc.gov/news-events/news/press-releases/2024/09/ftc-announces-crackdown-deceptive-ai-claims-schemes)
- **Ecommerce Empire Builders** (Sept 2024): "AI-powered Ecommerce Empire," "start a million-dollar business today," "$10,000 a month" claims. Training cost almost $2,000 and done-for-you stores tens of thousands. — [FTC, Sep 25, 2024](https://www.ftc.gov/news-events/news/press-releases/2024/09/ftc-announces-crackdown-deceptive-ai-claims-schemes)
- **Click Profit** (TRO Mar 5, 2025; announced Mar 18, 2025; S.D. Florida): "passive income" through a "proprietary system powered by artificial intelligence" on Amazon, Walmart and TikTok, described as "safe, secure, and proven to generate wealth." It implied ties to Nike and Disney and buyouts "at a 3-6x multiple," and charged a management fee of at least $45,000 plus inventory. At least $14M lost; most buyers lost everything; over one-fifth of Amazon stores earned nothing after fees, about another third grossed under $2,500 in their lifetime, and Amazon shut about 95%. Complainers were threatened with lawsuits under non-disparagement clauses. Aliases: FBALaunch, Automation Industries, PortfolioLaunch. — [FTC, Mar 18, 2025](https://www.ftc.gov/news-events/news/press-releases/2025/03/ftc-acts-stop-click-profit-online-business-opportunity-has-cost-consumers-least-14-million)
- Click Profit settlement (Aug 25, 2025): operators "permanently banned from the industry" and must surrender cash, real estate and property for redress (proposed or stipulated orders; one summary puts judgments over $20M). — [FTC, Aug 2025](https://www.ftc.gov/news-events/news/press-releases/2025/08/ftc-case-against-e-commerce-business-opportunity-scheme-its-operators-results-permanent-ban-industry); [PPC Land](https://ppc.land/ftc-settles-with-e-commerce-scheme-operators-in-massive-fraud-case/)
- **Growth Cave** (Mar 7, 2025; C.D. California): sold through YouTube ads. Promised "$20,000 to $50,000 in passive income," "It is literally IMPOSSIBLE to fail," a "$10,000 profit guarantee," and money within 4–6 weeks. The program cost thousands, plus a $30,000–$50,000 "Digital Freedom Mastermind" upsell. About $50M taken. Testimonial actors were undisclosed employees, and a "supposed AI-fueled program called PassiveApps" reused old testimonials. Charges included the Reviews and Testimonials Rule. — [FTC, Mar 7, 2025](https://search.ftc.gov/news-events/news/press-releases/2025/03/ftc-takes-action-stop-sprawling-growth-cave-business-opportunity-credit-repair-scam)
- **Air AI** (complaint Aug 2025; settlement Mar 24, 2026; D. Arizona): falsely claimed buyers "will or are likely to make substantial earnings" and that "Air AI Access Card or licenses are protected by a refund or buy-back guarantee." $18M judgment, largely suspended for inability to pay; $50,000 paid for consumer relief; banned from selling business opportunities. — [FTC, Mar 24, 2026](https://www.ftc.gov/news-events/news/press-releases/2026/03/air-ai-its-owners-will-be-banned-marketing-business-opportunities-settle-ftc-charges-company-misled)
- **DoNotPay** ("world's first robot lawyer," Sept 2024): $193,000 settlement over unsupported AI claims. — [FTC, Sep 25, 2024](https://www.ftc.gov/news-events/news/press-releases/2024/09/ftc-announces-crackdown-deceptive-ai-claims-schemes)

**Scale of the problem (FTC data)**
- 2024: "business and job opportunities" was the third most-reported fraud category, with $750.6M in reported losses, up nearly $250M from 2023. Job and employment-agency scam losses rose from $90M (2020) to $501M (2024) (FTC, Mar 10, 2025). — [FTC, Mar 2025](https://www.ftc.gov/news-events/news/press-releases/2025/03/new-ftc-data-show-big-jump-reported-losses-fraud-125-billion-2024)
- 2025: 3 million fraud reports and $15.9B in reported losses, up from over $12B in 2024 (FTC testimony, Mar 25, 2026). — [FTC JEC testimony](https://www.ftc.gov/news-events/news/press-releases/2026/03/ftc-testifies-joint-economic-committee-agencys-efforts-combat-fraud)

**How many people earn meaningful side or online income**
- Bankrate (YouGov, n=2,616 incl. 699 side hustlers, June 2–4, 2025; released Jul 9, 2025): 27% of US adults have a side hustle, the lowest since 2017 and down from 36% (2024) and 39% (2023). The average is $885 a month but the **median is $200 a month** (down from $250 in 2024). 35% use the money for regular living expenses. — [Bankrate press release](https://www.bankrate.com/press-releases/fewer-americans-have-a-side-hustle-in-2025/)
- LendingTree 2025: average $1,215 a month, median $400 (secondary roundup; different sample and definition). — [Omni Calculator roundup](https://www.omnicalculator.com/reports/side-hustle-statistics)
- Creators: Linktree's survey of 9,500 creators found 46% of full-time creators earn under $1,000 a year and 68% of part-time creators do (an older survey, about 2022–2023; likely stale). CreatorIQ (5,000+ creators, covered Aug 2026) says 67% earn under $10,000 a year and fewer than 5% over $100,000. NeoReach 2025 says more than half earn under $15,000 and 5% over $200,000. — [Built by Foundry (Linktree data)](https://www.builtbyfoundry.io/blog/why-96-percent-of-creators-dont-make-a-living); [Relevant Audience on CreatorIQ](https://www.relevantaudience.com/influencer/creatoriq-survey-creator-income-follower-count/); [Net Influencer on NeoReach](https://www.netinfluencer.com/over-half-of-full-time-creators-earn-below-us-living-wage-despite-250b-industry-neoreach-finds/)
- Conflict: an earlier CreatorIQ write-up (Jan 15, 2026; a 300-creator Sapio survey from July 2025) reports only 1% under $10K and 11% over $100K, which suggests a sample of established creators. It also gives a $3,000 median from payment data on 14,400 creators. — [Net Influencer, Jan 15, 2026](https://www.netinfluencer.com/creatoriq-survey-finds-creator-pay-skews-to-top-tier-despite-rising-influencer-marketing-spend/)

### Inferences
**Red-flag checklist (drawn from the cases above):**
1. "Passive," "AI-powered," "automated" or "done-for-you" stores, channels or apps sold for a large upfront fee ($2,000–$50,000+), especially with inventory bought on top.
2. Specific income promises ("$10K a month," "five figures by year 2," "7-figure business") or guarantees ("impossible to fail," "profit guarantee," "risk-free," "buy-back").
3. Testimonials that look like lifestyle marketing (cash fanning, cars), reused across brands, or given by staff.
4. Implied partnerships with big brands or VC buyouts ("3–6x multiple").
5. Contracts with non-disparagement clauses, pressure to edit reviews, refunds only after BBB or attorney-general complaints.
6. Upsell ladders into $30K–$50K "masterminds," and frequent rebrands (Passive Scaling → FBA Machine; KBA → PassiveApps; Click Profit → FBALaunch and others).
7. Store models where the seller operates on your Amazon or Walmart account. Platforms shut down most of these (about 95% in Click Profit).
8. YouTube and social ads as the main funnel (Growth Cave). The YouTuber Brandon saw may be legitimate, but income screenshots are not evidence. Check for verified numbers (Stripe or TrustMRR, platform dashboards on video, marketplace-verified P&L).

- For Brandon, the scam lesson cuts both ways. Don't buy a "system," and don't sell one: if he ever markets a course or tool, income claims need evidence (the Business Opportunity Rule and Section 5 orders above).
- The realistic baseline for a new side project is the median, about $200 a month after a year or more, not the averages or YouTube winners. Survivorship bias is extreme in creator and affiliate income, with most participants under $1,000–$10,000 a year.

## 5. Realistic time-to-income and weekly maintenance hours for content sites, channels, digital products and small software

### Takeaway
Search-driven projects are slow: only about 2–6% of new pages reach Google's top 10 within a year, and the average #1 result is about 5 years old. Sites that are "passive" at sale time still list 1–30 owner hours a week (Empire Flippers sellers' own estimates). The near-zero-hour ones have a paid VA doing the work. Plan on months to the first meaningful income and a standing 3–10 hours a week of human time, plus fixes when platforms change.

### Cited Findings
- Ahrefs (published May 15, 2025): of 1M random URLs first seen in September 2023, "Only 1.74%" reached the top 10 within a year. In a filtered sample of 2M English-content URLs (October 2023), 6.11% did. 40.82% of pages that made it did so within a month. After about 6 months outside the top 10, the chances are "pretty low" without changes. "On average, the #1 ranking page in Google is 5 years old," and 13.7% of top-10 pages were under a year old (down from 22% in the 2017 study). — [Ahrefs](https://ahrefs.com/blog/how-long-does-it-take-to-rank/)
- Empire Flippers listings, owner-stated weekly hours (via aggregators, 2026): a food content site needs about 10–15 hours a week (Feb 2026); a sports display-ad site about 25–30 hours a week, run solo (research, publishing, social repurposing); a home/food site about 2 hours a week because a VA does day-to-day work; a hobbies site about 1 hour a week (email and Facebook group). Older official listings show "Work Required Per Week" of 0–5 hours. These are seller estimates, not audited. — [Empire Flippers listing (example)](https://empireflippers.com/listing/40540/); [The Website Flip deal feed](https://thewebsiteflip.com/deal-feed/); [Off-market mirror of EF listing](https://offmarket-app-six.vercel.app/deal/empire_flippers_92290)
- Bankrate 2025: the median side-hustle income is $200 a month (see Q4). — [Bankrate](https://www.bankrate.com/press-releases/fewer-americans-have-a-side-hustle-in-2025/)
- Forced maintenance examples from automation platforms: GitHub disables scheduled workflows in public repos after 60 days without activity; Claude scheduled tasks turn off after 72 hours without GitHub access and are a research preview. — [GitHub Docs](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows); [Claude Code docs](https://code.claude.com/docs/en/routines)
- AdSense payouts start only at $100 in earnings, after identity verification ($0 threshold) and address PIN ($10 threshold). — [AdSense Help](https://support.google.com/adsense/answer/1709871?hl=en)
- The related notes in this folder give more figures: a 6-month-old 30-calculator site at −$50 a month profit on about 19.5K pageviews, a 15-year-old PDF tool at $1,197 a month profit (`software_tools_microsaas.md` Q2); maintenance hours and costs for small software (`software_tools_microsaas.md` Q6); time to first $100 or $1,000 a month for content sites (`content_sites_ads_affiliate.md` Q5); and YouTube Partner Program thresholds (`video_social_creator_income.md` Q1).

### Inferences
- **Content or SEO site:** expect 6–12+ months before steady Google traffic, if it ranks at all, and 3–10 hours a week of Brandon's review, approvals and fixes, even with Claude drafting. The first AdSense check needs $100 of earnings.
- **Short-video channel:** income depends on meeting monetization thresholds and on platform tolerance for AI content (Q2). Expect daily to weekly human review of every post.
- **Digital product or small software:** can earn sooner (first sale is possible in weeks) but needs support, refunds, payment-account upkeep and security fixes. That runs about 2–5 hours a week at small scale, per the other notes.
- **"Passive" in practice:** the businesses selling as low-hour all either have a VA (a cost) or are old and established. A new project Claude builds will not be passive in year one. The honest framing for Brandon: Claude can cut the hours to about a third of doing it alone, but he still owns approvals, accounts, money, customers and the platform risk.
- **Time budget fit:** since his main plan is bilingual ad packs for food trucks, a side project capped at about 3–5 hours a week with Claude doing the drafting is the most that won't eat the main business. Pick projects where the human hours are mostly 10–20-minute approvals.
